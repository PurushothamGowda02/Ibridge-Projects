GETTING A NEW GROQ API KEY
================================================================================

If you need to get your own API key:

1. Visit: https://console.groq.com
2. Sign up or log in with Google/GitHub
3. Navigate to "API Keys" section
4. Click "Create API Key"
5. Give it a name (e.g., "Metro Optimization")
6. Copy the generated key
7. Update .env file with your new key
8. Restart the application

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Chatbot not responding with AI"
Solution:
   - Check .env file has correct API key
   - Verify internet connection
   - Check console for error messages
   - Try getting a new API key from console.groq.com

Issue: "Import error: No module named 'langchain'"
Solution:
   - Run: pip install -r requirements.txt
   - Ensure virtual environment is activated
   - Check Python version (3.8+ required)

Issue: "API key invalid"
Solution:
   - Get new API key from https://console.groq.com/keys
   - Update .env file
   - Restart application
